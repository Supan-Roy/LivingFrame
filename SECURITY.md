# Security Policy

## Supported Versions

LivingFrame is actively maintained for the Amazon Developer Hackathon 2026. Security updates are applied to the active branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security and privacy of LivingFrame—particularly regarding room-sensing data, camera feeds, and ambient intelligence—very seriously.

If you discover a security vulnerability or privacy concern, please do **NOT** open a public issue. Instead, report it privately via email:

- **Security Contact**: Supan Roy
- **Email**: [contact@supanroy.com](mailto:contact@supanroy.com)

### When submitting a report, please include:

1. A clear description of the vulnerability.
2. Steps to reproduce the issue (including proof-of-concept scripts or payload if applicable).
3. The affected component or environment (e.g., Vega OS version, React Native Kepler version).
4. Potential impact and remediation suggestions, if known.

### Response Timeline

- **Initial Acknowledgment**: Within 48 hours.
- **Vulnerability Assessment**: Within 5 business days.
- **Fix & Public Advisory**: Coordinated responsibly after verification and remediation.
